This site is organised around projects rather than posts. Each network function and library gets a page describing what it does, how it is composed, and which tests prove it. The first is [UPF-NF](/projects/upf-nf/), the reference network function of the family.

The [composition](/composition/) page explains the layered split that keeps every network function small, and the [practices](/practices/) section will collect the coding rules that split depends on. The blog stays for news and longer-form notes.
