This site has been reset and rebuilt on a small, self-contained Jekyll theme. There is no theme gem to track and nothing to configure beyond a handful of files.

<!--more-->

## What you get

- A light and a dark colour scheme. The site follows the system setting by default, and the button in the header lets you override it. The choice is remembered.
- A home page listing posts, an archive grouped by year, and plain pages such as [About](/about/).
- Syntax highlighting, an RSS feed, a sitemap and SEO tags out of the box.

## Writing a post

Create a file in `_posts/` with the date and a slug in its name:

```yaml
---
title: My first real post
tags: [notes]
---

First paragraph, used as the excerpt on the home page.

<!--more-->

The rest of the post.
```

Code blocks pick up the theme colours in both modes:

```python
def greet(name: str) -> str:
    """Return a friendly greeting."""
    return f"Hello, {name}!"

print(greet("Omara"))
```

Tables work too:

| Element      | Where it lives            |
| ------------ | ------------------------- |
| Posts        | `_posts/`                 |
| Pages        | project root              |
| Menu entries | `_data/navigation.yml`    |
| Colours      | `_sass/_tokens.scss`      |

> Keep it simple. Add things only when a post actually needs them.
